Procedimento de instalação

  1. Windows. Abra o .exe e siga os passos.
  2. Se aparecer “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. O instalador não tem assinatura paga; o aviso é esperado.
  3. Linux, AppImage. Dê permissão de execução: clique com o botão direito → Propriedades → Permitir executar como programa, ou rode chmod +x Launcher-Project-Anomaly.AppImage.
  4. Linux, .deb. sudo apt install ./Launcher-Project-Anomaly.deb
  5. Primeira vez. Ao clicar em acessar, o launcher baixa o Java 17, o cliente 1.20.1 e o Forge. Leva alguns minutos e precisa de internet — depois disso abrir o jogo é direto.

Como instalar

  • Windows: abra o .exe e siga os passos. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações → Executar assim mesmo.
  • Linux (AppImage): clique com o botão direito → Propriedades → Permitir executar como programa, ou rode chmod +x Launcher-Project-Anomaly.AppImage.
  • Linux (.deb): sudo apt install ./Launcher-Project-Anomaly.deb
  • O que vem depois: o launcher baixa o Java 17, o cliente 1.20.1 e o Forge sozinho na primeira vez que você clicar em acessar. Precisa de uns minutos e de internet.
